# Sidenote 0.1.0-dev.1

The first public preview of Sidenote for Windows, on the Dev channel. It takes meeting notes on your own machine using Hex for transcription.

## Install
Download `sidenote-dev-Setup.exe` from this release and run it.

Needs on your laptop: Hex for Windows, which records and transcribes the meeting.

This build is not signed yet. Windows may show "Windows protected your PC". Choose More info, then Run anyway. Before you do, check the file against `SHA256SUMS` from this release.

## In this build
- Meeting notes from Hex recordings, with Stop and Pause that work in every live state.
- Notes, summaries and Ask keep running when you move to another page.
- Very long meetings are never cut short silently: Sidenote says when a transcript is too long for notes.
- Updates install in place from this release feed.
- A new Olive colour theme.
- New navigation and action icons.

## Known gaps
- Meeting start and end are not detected automatically yet. Use Start and Stop.
- Notes for transcripts over the length limit (about 250,000 characters) are not made yet.
- There is no colour picker yet; Olive is the only theme.
- The Home screen and sidebar redesign comes in 0.1.1. Workspace and team filters come later.
- The installer and app are unsigned.
- Speed and smoothness budgets are not yet enforced in CI.
- A 24-hour idle soak has not been run on this build.
